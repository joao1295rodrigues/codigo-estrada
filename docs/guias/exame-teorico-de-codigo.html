Como preparar o exame teórico de código

Como é a prova teórica de categoria B e um método simples de estudo com simulacros e revisão de erros.

Como é a prova

Segundo as informações que consultámos, a prova teórica de categoria B tem 30 perguntas de escolha múltipla e permite, no máximo, 3 erros (27 certas em 30). Confirma sempre as regras atuais no site do IMT, que é a fonte oficial.

Um método de estudo simples

  1. Estuda por tema. Faz o treino de uma categoria de cada vez (velocidade, prioridades, sinalização…) e lê sempre a explicação, mesmo quando acertas.
  2. Revê os erros. A secção "Rever os meus erros" guarda as perguntas que falhaste e tira-as da lista quando as acertas.
  3. Faz simulacros. Quando te sentires seguro, faz simulacros completos para treinares o ritmo e a concentração.
  4. Repete no dia seguinte. A memória fixa melhor com repetição espaçada.

Dicas para o dia do exame

  • Leia cada pergunta até ao fim, incluindo todas as opções, antes de responder.
  • Desconfie de respostas com palavras absolutas como "sempre" ou "nunca": raramente são as certas.
  • Em regras com valores (velocidades, distâncias, pontos), recorda o número e o contexto em que se aplica.
  • Se tens dúvida entre duas opções, pensa no que é mais seguro para todos os utilizadores da via.

Este site é um complemento de estudo. Não substitui as aulas de uma escola de condução nem o manual oficial.
