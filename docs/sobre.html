Sobre este site

Este é um site gratuito de treino para o exame teórico de condução em Portugal. Tem simulacros, treino por categoria com explicação e revisão automática dos teus erros. Funciona no telemóvel e também sem internet.

Como funciona

O teu progresso fica guardado apenas no teu dispositivo. Não é necessário registo. O site pode ser financiado por anúncios.

Fiabilidade do conteúdo

As perguntas são de treino e foram escritas com base no Código da Estrada. A legislação muda: confirma sempre no IMT e no teu manual de ensino. Este site não substitui as aulas de uma escola de condução.
