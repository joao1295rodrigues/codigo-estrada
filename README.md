# Código da Estrada: treino e simulacro

Site gratuito de treino para o exame teórico de condução em Portugal: simulacro, treino por categoria com explicação e revisão de erros.

- Site (GitHub Pages): https://joao1295rodrigues.github.io/codigo-estrada/
- Perguntas: `questions.js` · Configuração (email e AdSense): `config.js`
- Gerar o site: `OUT_DIR=docs node build.js https://ENDERECO-DO-SITE` (escreve na pasta `docs/`)
- Guias: `PASSOS.md`, `REVISAO-SINALIZACAO.md`

Conteúdo informativo e de treino. Não substitui o manual oficial; confirma sempre no IMT.
